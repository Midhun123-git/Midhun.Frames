# Midhun Frames — Cinematic Reality × Personal Imagination

A cinematic photography and videography portfolio showcasing creative visuals, storytelling, and memorable moments.

🌐 **Live Website:** https://midhun-frames.vercel.app

## 📌 About the Project

Midhun Frames is a photography and videography portfolio designed to present cinematic work through an immersive, modern interface. It includes a public portfolio and an admin dashboard for managing website content.

The project focuses on cinematic presentation, responsive design, optimized images, and a smooth browsing experience across desktop and mobile devices.

## ✨ Features

- 🎬 **Cinematic Portfolio** — Showcase photography and visual storytelling.
- 🖼️ **Dynamic Gallery** — Display images and videos managed through the admin dashboard.
- 🎨 **Interactive Photo Effects** — Black-and-white photography that transitions to colour through interaction.
- 📱 **Responsive Design** — Layout adapted for mobile, tablet, and desktop.
- 🛠️ **Admin Dashboard** — Manage portfolio content and website sections.
- ☁️ **Cloud Image Storage** — Cloudinary integration for media management.
- 🔐 **Authentication** — Protected admin access and user authentication features.
- 💬 **Contact Integration** — Connect with visitors through social and messaging options.
- ⚡ **Performance Optimization** — Image optimization and loading improvements.

## 🚀 Getting Started

### Prerequisites

Install the following before running the project:

- Node.js and npm
- MongoDB connection
- Git

### 1. Clone the repository

```bash
git clone https://github.com/Midhun123-git/midhun-frames.git
cd midhun-frames
```

### 2. Set up the frontend

```bash
cd client
npm install
npm run dev
```

### 3. Set up the backend

Open a second terminal:

```bash
cd server
npm install
```

Configure the required environment variables using your project's existing configuration and example environment file, if available. Then run the backend using the script defined in `server/package.json`.

**Note:** Required environment variables and start commands depend on the current project configuration. Never commit `.env` files, credentials, API keys, or private tokens.
